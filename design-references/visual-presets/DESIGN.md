# 内容驱动的阅读型展示

企业品牌与任务视觉要求优先。此规范是阅读、比较和核对资料的默认质量底线，不决定企业栏目或主题配色。

- 信息层级用排版、对齐、留白表达；主次区域有区别，不把每段都包装成相同卡片。
- 正文易读、条件可见；宽屏按内容分栏，窄屏单列；避免嵌套分栏使文字逐字换行。
- 数据使用等宽数字与真实单位；来源按钮低干扰但始终可找到；动作有 hover/focus 状态。
- 不存在实际企业图片时不拿装饰图冒充。所有标题与数值都受事实边界约束。
- 观察渲染后结果，再批量修正布局和交互；没有浏览器记录时不声称视觉通过。

本轮 Read 试用：纸白背景、深墨蓝文字、少量铜橙强调；衬线标题和清晰正文，分区以细线/留白组织，比较表和来源作为主要阅读工具。该试用风格不强加给其他企业。

## 边界

企业品牌规范优先；此文件不规定必须出现哪些企业栏目，不写入真实企业事实或素材。
