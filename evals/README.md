## B4 事实审查评测

已注册 `eval:b4`（`node evals/run-b4.ts`，默认关闭）用于 B4 纯虚构真实模型验收。真实评测需用户已有授权，并同时提供 `--live` 与 `APP_RUN_LIVE_EVAL=1`，显式指定 `--case <B4_CASE_ID>` 与 `APP_B4_REPORT_PATH`（私有新文件，`wx` 不覆盖）；缺项或未知 case 一律拒绝，绝不默认跑 all。`--budget-loopback` 仅容器内预算代理，禁止在宿主运行 SDK，文档不贴凭据，不新增真实视觉请求。

七个案例：正确、数值、单位、时间、主体各自差错，净利润缺失，以及同年同口径冲突。评测只做事实审查、内存报告、不采纳事实，使用独立上下文；报告只保存固定合成资料，不写 apiKey 或模型配置内容。

B4 v12于2026-10-12通过同一候选的七类最低验收：经授权网关调用deepseek-v4.1-flash，10次尝试取得7份有效报告，2次格式失败、1次连接失败原样保留。正确案例pass；数值、单位、年份、主体、关键缺失被定位并revise；两份来源的未解冲突needs_input。七份报告均经独立来源、引用、版本、严格JSON及未采纳状态核查，不混用旧版结果。

限制：模型仍可能输出围栏或前言，严格解析会拒绝；数值报告将真实定位额外标为source_locator失败，冲突报告将一致口径额外标为basis失败，属于次要检查类别混用。最低验收证明本组正确候选能通过且六类问题被拦截，不证明所有检查分类均精确或生产稳定性。全部尝试、明确重试决定和语义限制保存在Git忽略的`.local-data/pi-delegation/20261010-multimodal-review-100cny/b4-live-v12/`，摘要见[阶段报告](../docs/reports/pi-multimodal-review-100cny-2026-10-10.md)。
