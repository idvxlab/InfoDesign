完整候选、用量、账单及逐项核对保存在Git忽略的 `.local-data/b3-live/`，公开文档只保存非敏感摘要。每次评测固定资料与任务范围，登记模型、提示词版本、失败和未执行项；不得只报告最佳结果。追加付费测试以 [具体方案](cases/b3-quality-matrix.md) 和用户授权为准。
