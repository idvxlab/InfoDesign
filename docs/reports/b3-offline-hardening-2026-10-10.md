## 回放能证明什么

| 场景 | 程序结果 | 语义或证据边界 |
| --- | --- | --- |
| 首次候选：`legal_name` 及 partial 推断表格／图片 | 结构和实际读取通过，保存为待审 | 名称确定程度过强、范围说明无依据；人工标注保留，不能称语义通过 |
| 重验首版：同块 processed 与 unsupported | `coverage.duplicate_block`，保存无效版本 | 同时存在没有明确原文依据的别名 |
| 只修正重复覆盖 | 可保存待审版本，版本编号不同 | 别名问题不会因结构通过而消失 |
| 原文明确登记名称及简称的合成正例 | 可表达并通过程序检查 | 不把名称属性或 aliases 全局禁用，不用名称子串匹配冒充语义审查 |
| 修正截断、取消、超时、供应商错误 | 如实记录停止码、尝试数、用量缺口及可用的私有失败正文 | 不自动无界重试，不提交可用版本 |
| 修正未产生新响应 | 保留首版，修正尝试计数为 1 | 不从候选个数倒推次数，也不伪造第二份正文 |

`annotations.json` 是针对合成样例的人工标注，不是生产语义判定器。真实 SDK 连接的仍是本地模拟 SSE 网关：证明请求／工具／保存路径，不证明真实模型遵循提示。旧重验第三次响应的正文、停止码与分次用量当时没有保存，不能恢复其真实失败原因；本轮 `length/error/aborted` 测试均为独立合成场景。

仅保存 SDK 实际交付的正文；请求开始前失败、没有正文或尚未到达客户端的数据不能重建。失败正文仍留在私有候选存储，安全运行摘要不会包含原文或供应商原始错误。

## 5 元预算与下一次最小验收

用户已授权后续 B3 测试累计人民币 5 元，通过即停；每任务最多 4 次模型调用、2 次读取、一次结构修正、每响应 4096 输出 token、120 秒，沿用同一网关／模型及已批准 PDF 段落。原两次真实记录只作对照，不回传给模型，也不扩大资料范围。

只读核对结果：`.pi/extensions/rmb-cost/rates.json` 采用人民币／百万 token 的暂估假设，普通输入 1.92、输出 7.68，缓存读取 0.04 尚未平台确认，缓存写入为未知。既有截图核验记录明确未显示币种和 token 计价基数。`models.json` 没有计价、余额或配额查询字段；项目内未发现可验证的账单／余额接口。运行层的 `cost: 0` 仅为 SDK 元数据，`billedAmount: null` 表示实际金额未知。以上无法证明实际单位、平台扣款或可预留的最大费用。

因此，本轮新增网关请求为 0，5 元授权没有被用作按猜测价格反复尝试的依据。恢复付费步骤需要同一网关的可验证完整费率（含币种、基数、缓存及附加费用）、请求输入成本上界与可执行的费用预留条件，或网关侧可确认的专用 5 元限额。本轮没有创建持久权限、调整账户额度、充值或订阅。

如果转用次数／token 配额，需要明确采用这种计量边界：每任务 4 次请求与每响应 `max_tokens=4096` 可由现有程序限制，N 个任务的累计请求输出额度最多 16,384N；请求上下文另可限制为每次 128,000 字节。字节不是网关计费 token，`max_tokens` 是请求限制而非实际扣款证明；缺少供应商 tokenizer／输入计费规则时，不能承诺准确的输入 token 或人民币硬上限。跨任务额度还须由私有验收台账在每次请求前预留，不能只加总最终成功响应。

计价条件具备后，最小真实验收先运行同一授权段落的一个独立任务：只传既有段落与当前角色指令，逐请求记录标准停止码／用量，预留最大输入输出费用，不确定请求按预留额计入累计。检查覆盖互斥、名称与别名依据、partial 范围、缺失不编造、原文摘录及候选完成状态；失败先复盘并离线验证，再决定有变化的重验。费用或用量不确定到无法继续安全预留时停止。该单段通过仅关闭本轮回归，数值、年份、不同口径和多源冲突的 B3 完整质量验收仍需既定合成案例的真实结果，不能未经授权扩大材料。
