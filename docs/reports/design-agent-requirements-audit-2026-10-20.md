## 完整能力清单

| 能力 | 要求与边界 | 主要依据 |
| --- | --- | --- |
| 理解任务与信息全景 | 读取服务授权、版本固定的事实及企业全景；结合目标、受众、约束、视觉规则与真实组件目录；按需查询事实、关系、事件、素材和原文，不只看上游摘要 | 总方案 §5.2 |
| 内容驱动的信息架构 | 自主选择内容、叙述主线、分组、层级、优先级与浏览路径，记录有意义的省略及理由；不同资料或受众产生合理不同的组织，不套固定栏目 | 总方案 §1、§6；协议 §3 |
| 视觉与交互设计 | 把信息关系映射为恰当表达，设计布局、排版、主题、响应式与交互；重要条件和来源保持可见；视觉规范不固定内容结构 | 总方案 §12—13；协议 §4 |
| 两层结构化产物 | 首次提交 InformationPlan 与 PageSpec；计划可随视觉细化调整且变化可追踪。稳定节点、准确版本、组件与数据绑定、受控动作由程序解释；同一个设计 Agent，不要求两次模型调用 | 总方案 §5.2、§6 |
| 事实忠实与溯源 | 不改权威事实、不编造关系、不夸大结论；数值由绑定读取，保留主体、单位、时间、工况；文本片段、数据点、关系边和素材关联证据；支持派生计算时由程序计算并保存输入和方法 | 总方案 §11；协议 §4 |
| 真实能力匹配 | 只使用可用且版本匹配的组件；检查参数、动作和数据条件；能力不足明确提出组件需求，不能偷偷丢信息或用不等价表达冒充成功 | 总方案 §12、§14 |
| 预览与定向修正 | 能接收实际渲染、浏览器检查和独立审查反馈，按节点/事实定位问题并有限修正；设计问题返回设计，事实问题返回证据阶段；自检不能替代独立审查 | 总方案 §5.2、§8、§10；接手计划 D3—D4 |
| 自然语言修订 | 基于当前页面、旧计划/规格、目标节点、基础版本及允许范围；必要时修改计划，提交 ChangeSet 与新候选；保留无关内容，程序检测未申报变化 | 总方案 §9 |
| 事实更新后的设计适配 | 由证据流程先核验新事实，再沿依赖更新受影响内容；结构仍适用时可仅更新绑定数据，不强制再调用设计 Agent | 总方案 §9.4 |
| 执行与停止 | 独立 Pi 业务上下文、服务授权只读工具、预算、取消与有限修正；缺信息/缺组件/技术失败明确区分；候选 completed 不代表页面通过或已发布 | 总方案 §2、§4—5、§10、§17 |

## 静态核对的当前缺口

- `apps/server/src/agents/design/agent.ts` 已有真实 SDK 会话接线、候选校验与最多一次程序校验反馈修正；没有实际预览/页面审查反馈闭环。本轮未重新执行验证。
- `apps/server/src/agents/design/prompt.md` 与 DesignInput 仅支持首次生成。
- `context.ts` 提供实体/事实索引，但关系、事件、素材只有数量；`tools/design.tools.ts` 仅有 catalog/claim/evidence 三类读取，原文只接受 paragraph。不能据此宣称完整全景查询或多模态素材设计已完成。
- PageSpec Schema 当前仅含 page、fact_text、comparison_matrix、disclosure 四类接口，布局与交互有限。协议文档明确素材、自由概括、派生计算、任意组件与局部修订未实现。接口存在不证明组件已实现。
- `packages/page-renderer/src/`、`packages/ui-components/src/` 当前仍是注释占位，不能实际生成并验收可交互页面。
- `packages/contracts/schemas/change-set.schema.json` 仍拒绝所有输入，`orchestration/revise.workflow.ts` 为占位，自然语言局部修订未落地。
- 交接记录只证明一个合成资料真实任务的历史通过记录，不满足跨资料、跨受众及完整页面验收。

渲染、浏览器检查、版本存储、独立页面审查是配套服务或其他角色的职责，不能全部塞进设计 Agent；但缺少这些协作能力，就不能宣布设计到页面闭环完成。

## 验收与实施边界

首次生成闭环至少验证两类不同结构资料，以及同一事实的两种受众/目标；分别检查事实忠实、结构合理、真实交互和来源定位。覆盖缺资料/冲突、缺组件、非法引用/脚本、失败/取消/截断。详见接手计划最小验收矩阵。

完整产品还需总方案 A02/A03 的局部修订、A04 的事实更新、A08 的并发版本保护和 A09 的来源访问。首轮 D1/D2 暂缓修订不等于永久取消要求。自动组件工程、完整 A2UI、额外主管 Agent 均不是首版必需；不新增每次人工发布审批。

总方案 §18.4 的信息架构合理率、信息与表达匹配率、层级合理率各 ≥90%，页面生成成功率 ≥95%，严重视觉错误率 ≤1% 等是需求书建议目标，需要定义评测集与统计口径，不是现有成绩。
