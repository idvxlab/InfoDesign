# B3 信息与证据 Agent：本地实现与验证

日期：2026-10-10。范围为首次生成、已授权的段落型 DocumentIR、候选快照与程序检查。本轮没有真实模型调用；B3 的模型提取质量未验收，B4—B6 不据此标记完成。

## 已实现

- `agents/evidence/agent.ts` 使用 Pi SDK 0.99.1 的独立会话完成任务。固定角色提示和提取／归并 Skills 从仓库白名单路径加载，关闭个人与上传目录扫描、扩展、内置 Shell 和自动重试。
- 输入先通过 B1 权限、协议及资料检查；模型初始上下文只收到资料目录、任务约束、预算、输出 Schema 和程序指定版本。原文必须经 `read_document` 读取，最终回复为完整 EvidenceOutput。
- 候选沿用现有协议，保留主体、值、单位、时间、口径、来源、关系、事件、素材引用、缺失与冲突。未支持或未处理块必须登记，不能宣称全部完成。不同年份和口径不由程序硬判为冲突。
- 服务层复用 B1 校验，并增加实际读取回执、覆盖完整性、运行来源／版本、重复事实和冲突关联检查。程序不判断所有事实语义是否真实，候选始终为 pending。
- `MemoryCandidateStore` 追加保留无效输出、失败原因和通过程序检查的候选。最多一次结构修正，使用新快照版本；保留旧事实编号、已合法的事实值、缺失和冲突，不维护权威版本指针。
- 新增默认关闭的 `eval:b3`，仅使用固定合成输入，不读取预期答案。原始候选写入显式私有报告，终端只输出状态和用量摘要；报告路径须在请求前可创建，已有报告不可覆盖。

## 实现边界

当前只接收 generate 且不带 existingSnapshot 的任务；同一 documentId 的多个版本暂拒绝，避免现有 unsupported 字段缺少版本号带来的歧义。非段落定位仍由已有 B1 检查拒绝，没有放宽 Schema 或伪装文件解析。

候选保存在任务级内存存储；真实验收 CLI 可将本次结果导出为私有报告。这不等于数据库持久化、幂等工作流或原子采纳。关系／事件及来源通过通用协议表达；图片、表格、OCR 和视觉能力未实现。

结构修正只能防止可确定的删除和合法事实值改写；同义归并、单位换算、遗漏事实和真实冲突判断仍需独立审查。预算按请求次数、工具次数、输出 token 上限及上下文字节控制，不把字节上限称为模型真实上下文能力。
