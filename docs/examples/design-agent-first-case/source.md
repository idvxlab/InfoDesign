## P01｜公司介绍

澄野环境监测是一家虚构的室内环境监测设备企业，成立于 2018 年。公司提供用于室内温湿度记录和二氧化碳监测的设备。本资料介绍三个型号：CY-T1、CY-C2、CY-G3。

## P02｜产品比较口径

以下信息均来自本合成资料 v1，描述三个型号的标准配置。三个型号的采样间隔均为 60 秒；采样间隔不是响应时间。温湿度表示同时监测温度与相对湿度；本资料未提供测量精度、量程及认证信息。

## P03｜CY-T1 标准配置

CY-T1 监测温度与相对湿度，不监测二氧化碳。它采用 USB 供电，通过 USB 导出本地记录，不支持 Wi-Fi。厂家在本合成资料中列出的应用场景是档案室的本地温湿度记录。

## P04｜CY-C2 标准配置

CY-C2 监测温度、相对湿度与二氧化碳。它采用 USB 供电，支持 Wi-Fi 联网，并通过平台导出记录。厂家在本合成资料中列出的应用场景是教室的联网环境监测。

## P05｜CY-G3 标准配置

CY-G3 监测温度、相对湿度与二氧化碳。它采用 PoE 供电，使用以太网联网，并通过平台导出记录。厂家在本合成资料中列出的应用场景是办公楼的有线部署。没有资料证明它比 CY-C2 的测量精度更高。

## P06｜发展事件

2018 年，公司成立。2021 年，推出 CY-T1。2023 年，推出 CY-C2。2025 年，推出 CY-G3。本资料没有提供销量、市场份额、客户名称或获奖记录。
