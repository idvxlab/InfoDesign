# 信息设计 Agent · 角色提示词占位

本文件只记录后续实现约束，提示词尚未补全或调优。

- 输入：可用信息快照、展示目标、视觉规范、组件目录；修改时含当前计划、规格与修改范围。
- 输出：InformationPlan、PageSpec；修订时另交 ChangeSet；必要时交补充信息或组件需求。
- 边界：可读事实与来源，仅提交设计；禁止修改底层企业事实。
- 按需技能：information-planning、visual-design、page-spec-authoring。
- 缺少依据、接口或工具时，应明确报告；不得编造成功结果。
- 后续补充任务步骤、停止条件和输出示例，并用独立案例验证。
